# Data Cleaning and Preparation Project

## Project Overview

This project focused on cleaning and preparing a raw dataset for analysis. The objective was to improve data quality, ensure consistency, and prepare the dataset for reliable exploratory data analysis (EDA) and visualization.

Data cleaning is a critical stage in the data analytics workflow, as the quality of insights generated depends heavily on the quality of the underlying data.

---

## Dataset Description

The dataset contained customer order information, including:

* Order Details
* Customer Information
* Product Information
* Payment Methods
* Order Status
* Referral Sources
* Revenue Data

The raw dataset contained several data quality issues that required cleaning before analysis.

---

## Data Cleaning Process

### 1. Data Inspection

The dataset was first explored to understand its structure, data types, and potential quality issues.

Actions performed:

* Reviewed column names
* Examined data types
* Checked for inconsistencies
* Assessed overall data quality

---

### 2. Duplicate Detection and Removal

Duplicate records can lead to inaccurate analysis and inflated metrics.

Actions performed:

* Identified duplicate rows using the Power bi Duplicate function
* Verified duplicate records
* Removed redundant entries while retaining valid records

Outcome:

* Improved data integrity
* Prevented double-counting during analysis

---

### 3. Missing and Null Value Handling

Missing values were identified across relevant columns and addressed appropriately.

Actions performed:

* Detected NULL and blank values
* Evaluated the impact of missing records
* Replaced missing values where necessary
* Standardized incomplete records to maintain consistency

Outcome:

* Reduced data gaps
* Improved dataset completeness

---

### 4. Data Formatting and Standardization

Very few columns required formatting corrections, but checks were made to ensure consistency.

Actions performed:

* Standardized date formats
* Corrected inconsistent text entries
* Validated numerical fields
* Ensured uniform column formatting

Outcome:

* Improved data consistency
* Enhanced analytical readiness

---

### 5. Data Validation

Following the cleaning process, validation checks were performed to ensure accuracy.

Actions performed:

* Verified row counts
* Checked for remaining duplicates
* Confirmed data type consistency
* Validated calculated fields

Outcome:

* Produced a reliable and analysis-ready dataset
